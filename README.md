# intex.click

Сайт ООО «ИНТЕХ» (Калининград): сайты, SEO и Яндекс Директ, IT-инфраструктура.

WordPress, собственная тема `intech` — `wp-content/themes/intech`.

- `inc/landings.php` — страницы услуг (без создания страниц в админке);
- `inc/legal.php` — «О компании», «Контакты», политика конфиденциальности, SEO-разметка;
- `inc/articles.php` + `inc/articles/*.php` — блог (статьи хранятся в теме);
- `inc/metrika.php` — Яндекс Метрика и цели;
- `inc/contacts.php`, `inc/logo.php` — контакты и логотип.

Хостинг: Beget, папка `/intex.com/public_html`. Ядро WordPress и `wp-config.php` в репозиторий не входят.
