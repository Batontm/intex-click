Положите сюда видео для первого экрана с именем hero.mp4 — оно подставится автоматически.

Рекомендации:
- формат MP4 (H.264), 1920x1080, 10–20 секунд, без звука, до 8–10 МБ;
- бесплатные ролики: pexels.com/videos, mixkit.co — запросы "server room", "data center", "office team", "coding";
- используйте только видео, на которое у вас есть права (своё или со свободной лицензией).

Другой вариант: загрузить ролик в админке — Внешний вид → Настроить → «ИНТЕХ: оформление и контакты» → Видео на первом экране.
